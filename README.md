📚 BookVerse - Plataforma de Gestão de Livros
Disciplina: Interfaces Web 2025-2026
Alunos: Constança Azevedo (A25969) & Rui Dias (A25957)

🎯 Sobre o Projeto
O BookVerse é uma aplicação web moderna para gestão e exploração de um catálogo de livros. Desenvolvida em ReactJS, oferece uma experiência dupla:

🎭 Frontoffice Público: Interface intuitiva para leitores explorarem livros, lerem sinopses e participarem na comunidade através de comentários

🔐 Backoffice Administrativo: Área segura para gestores administrarem o catálogo com operações CRUD completas

Este projeto foi desenvolvido como trabalho prático para a disciplina de Interfaces Web, cumprindo todos os requisitos técnicos exigidos para uma solução avançada (até 18 valores).

✨ Funcionalidades Principais
🎨 Frontoffice (Público)
📖 Catálogo de Livros: Listagem paginada com capas atrativas

🔍 Sistema de Pesquisa: Encontre livros por título, autor ou género

📚 Páginas de Detalhes: Informação completa sobre cada livro

💬 Comunidade: Sistema de comentários e avaliações

🎯 Recomendações: Sugestões de livros similares por género

📱 Design Responsivo: Experiência otimizada para mobile e desktop

🔧 Backoffice (Administração)
🔐 Autenticação Segura: Login protegido com credenciais

📊 Dashboard: Visão geral das estatísticas da plataforma

🔄 CRUD Completo: Criar, ler, atualizar e eliminar livros

👥 Gestão de Autores: Segunda entidade com relacionamentos

💬 Moderação: Controlo de comentários da comunidade

📈 Análises: Métricas de utilização e popularidade

🏗️ Arquitetura Técnica
Frontend
⚛️ React 18: Biblioteca principal com hooks modernos

🚀 Vite: Build tool rápido e eficiente

🧭 React Router v6: Navegação entre páginas

🎨 CSS Modules: Estilos componentizados e reutilizáveis

🔐 Context API: Gestão de estado e autenticação

📱 Responsive Design: Mobile-first com media queries

Backend & API
📡 REST API: Endpoints seguindo convenções RESTful

🔄 JSON Server: Simulação de API durante desenvolvimento

☁️ Sheety (Planejado): Integração com Google Sheets como backend

🔒 Autenticação: Sistema baseado em tokens JWT
